Sobre o FitPlan

O FitPlan é um projeto de portfólio que une saúde, alimentação e treino em uma única plataforma simples e direta. A ideia é permitir que qualquer pessoa informe alguns dados básicos — peso e objetivo — e receba, em segundos, uma sugestão de cardápio semanal e uma rotina de treino personalizada de acordo com esse objetivo.

Este é um MVP (Produto Mínimo Viável): a primeira versão funcional do projeto, construída para validar a ideia central antes de evoluir para um sistema mais completo.

Tecnologias utilizadas

🐍

Python + Flask

Backend e lógica de geração de dieta e treino.

🗄️

SQLite

Banco de dados leve para registrar as solicitações.

🎨

HTML, CSS e JS

Interface responsiva, moderna e sem dependências externas.

Próximos passos do projeto

Este MVP foi construído com uma arquitetura pensada para crescer. Os próximos passos incluem:

  • Login e cadastro de usuários
  • Histórico de dietas geradas
  • Histórico de treinos gerados
  • Cálculo detalhado de calorias
  • Cálculo de macronutrientes
  • Mais objetivos e perfis
  • Ampliação da base de alimentos
  • Ampliação da base de exercícios
  • Imagens e vídeos dos exercícios
  • Dashboard do usuário
  • Integração com APIs externas
  • Acompanhamento de evolução (peso e medidas)
  • Gráficos de progresso
  • Personalização com IA
  • Evolução para um modelo SaaS
